# 📱 [Tracker Companion]

A custom, offline-first companion app eliminating use of excel sheets for tracking stats and simulation data for a game mode.

## 🚀 Features
* **Bottom Tabs:** Dashboard, Roster, etc. tabs for managing the simulation flows.

## 🛠️ Tech Stack & Architecture
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose
* **Local Database:** Room DB for local data persistence
* **Asynchronous Logic:** Kotlin Coroutines & StateFlow
